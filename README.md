# kevin ongaro — portfolio

Personal portfolio. One static page, one stylesheet, no build step.

```
index.html   the whole site
style.css    the stylesheet
```

## Run it

```sh
python3 -m http.server 5173
```

Then open <http://localhost:5173>.

## Deploy

Static site on Vercel — no build command, output directory is the repo root.

## Notes

`Kevin_Ongaro_CV.pdf` must sit in the repo root; the résumé button links to it
directly.
